# Методика управленческого P&L

## Представление и знаки

Для нового шаблона предложи рубли или тысячи рублей и отдельные колонки «Факт», «План», «Отклонение», «Отклонение, %». Не меняй уже принятую конвенцию без необходимости. В показанном ниже варианте доходы и расходы хранятся положительными величинами в своих статьях, сторно — отрицательными; расходы вычитаются формулами. Переход от дебета/кредита или signed-данных источника должен быть явным.

Базовая структура с полной производственной себестоимостью:

| Строка | Расчёт или содержание |
|---|---|
| Чистая выручка | Признанная выручка за минусом скидок и возвратов, с согласованным режимом НДС |
| Себестоимость проданного | Стоимость реализованных изделий/услуг по закрытому периоду; раскрытие материалов, труда, кооперации, накладных — внутри итога |
| Валовая прибыль | Выручка − себестоимость проданного |
| Коммерческие расходы | Признанные расходы на сбыт, не включённые выше |
| Управленческие расходы | Признанные расходы управления, не включённые выше |
| Прочие операционные доходы/расходы | Раздельно, по утверждённой классификации |
| EBIT | Валовая прибыль − коммерческие − управленческие + прочие операционные доходы − прочие операционные расходы |
| EBITDA, справочно | EBIT + амортизация, включённая в себестоимость проданного и операционные расходы этого P&L |
| Финансовые и другие неоперационные статьи | Отдельный мост от EBIT; классификация должна исключать повторное включение |
| Прибыль до налогообложения | EBIT + неоперационные доходы − неоперационные расходы |
| Расход по налогу на прибыль | По принятой методике и источникам, не по банковской оплате; ставка не задана навыком |
| Чистая прибыль | Прибыль до налогообложения − расход по налогу |

EBITDA — справочный показатель, а не слагаемое прибыли до налогообложения. При другой системе налогообложения согласуй название и место налоговых статей; не вставляй автоматически «налог на прибыль». Отсутствующие статьи не приравнивай к нулю без подтверждения.

Маржинальный доход = выручка − переменные затраты по согласованному определению. Показывай его отдельным аналитическим срезом, если есть достоверное деление постоянных/переменных расходов; он не заменяет валовую прибыль. Не считай все прямые затраты переменными.

## Производственная себестоимость

Приоритет — сверенная себестоимость продаж из выбранного контура учёта. Если строишь её расчётно, составь мосты по каждой площадке и единице валюты:

- НЗП на начало + включаемые затраты производства + входящие перемещения НЗП − НЗП на конец − исходящие перемещения НЗП − отдельные выбытия НЗП = себестоимость выпуска.
- Готовая продукция на начало + себестоимость выпуска + поступления готовой продукции − готовая продукция на конец − отдельные выбытия и исходящие перемещения, не являющиеся продажами = себестоимость проданного.

Возвраты, уценки, брак и корректировки прошлых периодов раскрывай отдельными движениями с направлением; не подгоняй остатки ради нулевой разницы. Если мосты не сходятся, покажи разрыв и оставь отчёт предварительным.

Покупка металла не равна потреблению в производстве; потребление не равно стоимости проданных изделий. Аналогично, зарплата цеха, амортизация и кооперация могут оставаться в НЗП/готовой продукции. Не включай всю сумму этих затрат дополнительно к уже рассчитанной себестоимости продаж.

Определи порядок учёта нормальных отходов, возвратного металла, брака, простоев и ремонтов по действующей методике. Не капитализируй аномальные потери автоматически. Не вводи произвольные коэффициенты распределения производственных накладных: запиши базу, мощность, состав пула и нераспределённый остаток. Новый проект правил отделяй от действующих правил.

Закупку станка, погашение тела кредита, взносы собственника и дивиденды не превращай в текущие операционные расходы. Для спорных капитальных/текущих затрат используй документы и принятую политику; не задавай налоговые пороги по памяти.

Возмещаемый НДС по согласованной методике обычно исключается из доходов и затрат; невозмещаемый НДС требует отдельной классификации. Не дели все суммы на один коэффициент: ставки, освобождения и право на вычет могут различаться. Ставки проверяются отдельно.

## Общие расходы и свод

Для каждого пула зафиксируй: период, организацию, состав статей, площадки-получатели, базу распределения, исключения, валюту и допуск округления. Примеры возможных драйверов: площадь для аренды, подтверждённые машино-часы для оборудования, фактические трудозатраты для сервисных функций. Выручка не является универсальным драйвером.

Доля площадки = её база / сумма баз получателей. При нулевой сумме баз оставь пул нераспределённым и объясни причину. Не распределяй отрицательные или отсутствующие базы автоматически. Округляй на выходе; явно учитывай округлительный остаток.

В сверке «сумма площадок + корпоративный центр» общие расходы должны остаться один раз: из корпоративного центра уходит ровно распределённая сумма. Для анализа ответственности сохраняй вид до распределения.

Внутренние движения между площадками одного юрлица не являются внешней выручкой компании. Для нескольких организаций обозначь периметр консолидации и пары внутренних операций. В своде покажи отдельную колонку элиминаций: обороты, соответствующие расходы и нереализованная внутренняя прибыль в остатках. Не удаляй только внутреннюю выручку и не исключай всю себестоимость, если часть приобретённого осталась на складе. Неизвестная пара или маржа в остатках блокирует статус «сверенный» для соответствующей консолидации.

## План-факт

Абсолютное отклонение = факт − план. Процент = (факт − план) / ABS(план), если план не равен нулю; при нулевом плане показывай «н/д» и абсолютную разницу. При отрицательном плане поясни выбранную конвенцию.

Благоприятность отклонения отделяй от его знака: рост выручки/прибыли обычно благоприятен, рост расходов — неблагоприятен. Для строк со смешанным смыслом не назначай цвет автоматически. Изменение рентабельности показывай в процентных пунктах. Итоговая рентабельность = итоговая прибыль / итоговая выручка; не среднее месячных процентов. При нулевой выручке — «н/д».

Сравнивай YTD с тем же диапазоном месяцев плана. Новый прогноз = факт закрытых месяцев + прогноз оставшихся, без повторного счёта границы. Прогноз не переписывает утверждённый бюджет. Причины отклонений подтверждай данными объёма/цен/ассортимента/затрат, а гипотезы маркируй.

## Первичные справочные источники

Проверено при подготовке пакета 18 сентября 2026 года:

- [IFRS Foundation: IAS 2](https://www.ifrs.org/issued-standards/list-of-standards/ias-2-inventories/) — состав стоимости запасов и признание стоимости проданных запасов в расходах соответствующего периода.
- [IFRS Foundation: IAS 7](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/) — различие прибыли и денежных потоков, неденежные корректировки.

Это ориентиры для экономической логики, не утверждение применимости МСФО к пользователю и не готовая нормативная политика. Для регламентированной отчётности и налогов проверяй применимые действующие правила отдельно.
